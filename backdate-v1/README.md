backdate-v1.py

A little Python script (V1) that calculates your (approximate) conception date.

About this project

This is my first time messing around with Python in a good while, so I kept it simple on purpose. The goal was just to practice the basics:

variables
taking user input
if elif else
a bit of logic to work out a date from that input

Nothing fancy — just wanted to get back into the swing of writing Python and have something small and fun to show for it.

Future plans

Eventually moving onto menu options, a database, etc.
